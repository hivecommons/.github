# Hive Adopters

The canonical adopters list lives in the Hive repository:

**→ https://github.com/hivecommons/hive/blob/HEAD/ADOPTERS.md**

That file is the single source of truth for who runs Hive and at what
adoption level (evaluation / development / production). This copy used to
carry a second, hand-maintained table that drifted from the canonical one
(Project Bluefin was missing; tunaos.org was shown as development while
the canonical list — backed by each adopter's own hive config, README and
linked production evidence — records both as Production). To avoid that
drift recurring, this file is now only a pointer.

## How to add or update your organization

Open a pull request against
[`hivecommons/hive` `ADOPTERS.md`](https://github.com/hivecommons/hive/blob/HEAD/ADOPTERS.md)
following the instructions at the top of that file (one row, DCO-signed,
own organization only, public reference supporting the entry). Adoption
status should be derivable from the adopter's own hive configuration or
README; cite it in the row.
