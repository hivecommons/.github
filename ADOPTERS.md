# Hive Adopters

Organizations and projects using Hive in evaluation, development, or
production. This list exists to help the community and the CNCF gauge
real-world adoption — thank you for adding yourself.

## How to add your organization

1. Open a pull request against this file adding **one row** to the table,
   keeping the list alphabetical by organization.
2. Sign your commit (`git commit -s`) like any other contribution.
3. Use an email/handle affiliated with the organization, or link a public
   reference (blog post, talk, repo) that supports the entry.
4. Only add your **own** organization. Maintainers will not add adopters
   on hearsay, and entries may be verified before merge.
5. To update or remove your entry later, open another PR.

**Adoption levels:** `evaluation` (trying it out), `development`
(pre-production / internal tooling), `production` (running real
workloads).
