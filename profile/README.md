# Hive Commons

**Hive Commons** is the umbrella community for **Hive** — an AI-agent fleet orchestration system that runs governed swarms of coding agents against real repositories: a multi-tenant hub, hosted spokes, ACMM maturity-model governance, audited agent attribution, and formally verified coordination protocols.

## Projects

| Project | What it is | Where it lives today |
|---|---|---|
| **Hive** | Agent fleet orchestrator (hub + spokes) | [kubestellar/hive](https://github.com/kubestellar/hive) |

> Code has not yet migrated to this organization. Hive Commons is being established as the project's long-term neutral home; repositories will move here with full git history preserved.

## Governance

Hive is maintained by a three-member Maintainer Committee spanning three organizations, with a documented contributor ladder, DCO-signed contributions, and explicit governance for AI-agent contributions (every merge is accountable to a human maintainer). Governance documents will be published here following maintainer review.
